# Vibe智购AI 项目简介

## 项目定位

这是一个基于 Android 的 AI 辅助购物 Demo，用于学习和求职展示。项目包含电商基础流程（浏览、加购、下单、订单管理），并加入了 AI 购物助手功能，用户可以用自然语言描述需求，获取个性化的商品推荐。

## 核心功能

### 电商基础流程
用户可以注册登录、浏览商品分类、搜索商品、查看详情、添加购物车、下单、查看订单状态、发表评价。数据存储在本地 SQLite，不依赖后端服务。

### AI 购物助手
用户输入购物需求（如"我想买一台适合学习的平板，预算3000左右"），AI 助手会：
1. 解析用户意图：提取品类、预算、用途等关键信息
2. 匹配商品：从商品库中筛选符合条件的商品
3. 生成推荐：返回推荐商品和理由
4. 一键加购：用户可以直接把推荐商品加入购物车

推荐记录会保存到数据库，用户可以随时查看历史推荐，方便对比。

### 多端支持
- **Android App**：原生应用
- **PWA 版本**：可在 iPhone Safari、Android 浏览器、桌面浏览器上访问，无需安装

## 技术实现

### Android 端
- **开发语言**：Java
- **UI 框架**：XML Layout + AndroidX + Material Design
- **架构**：Activity + Fragment
- **数据存储**：SQLite（用户、购物车、订单、推荐记录）
- **网络请求**：OkHttp
- **AI 集成**：DeepSeek / OpenAI 兼容 API（可选）

### AI 功能
- **意图解析**：正则表达式和关键词提取，识别品类、预算、用途
- **商品匹配**：基于规则的筛选和打分排序
- **大模型增强**：如果配置了 API Key，调用大模型生成更自然的推荐文案；如果没有，使用本地规则生成
- **兜底策略**：即使没有网络或 API，本地推荐功能也能正常工作

### PWA 版本
- **技术栈**：HTML5 + CSS3 + 原生 JavaScript（无框架依赖）
- **PWA 特性**：Service Worker 离线缓存、Web App Manifest
- **响应式设计**：适配移动端和桌面端

## 项目亮点

### 1. 业务闭环设计
不只是堆功能，而是设计了清晰的用户路径：
- 注册登录 → 浏览/AI推荐 → 加购 → 下单 → 订单管理 → 评价

### 2. AI 与业务结合
推荐不只是文本回复，而是打通了业务流程：
- 推荐结果可以直接加入购物车
- 推荐记录保存在数据库，可随时查看
- 从推荐到下单形成业务闭环

### 3. 工程化实践
- **配置隔离**：API Key 通过 local.properties 管理，不提交到 Git
- **代码分层**：ai/、cart/、home/、user/ 等模块职责清晰
- **.gitignore 完善**：避免提交 .idea、build 产物、敏感信息
- **兜底策略**：无网络或 API 时仍能完成基本推荐

### 4. 展示友好
- Android + PWA 双端，降低体验门槛
- PWA 支持 iPhone，HR 可以直接浏览器访问
- 代码结构清晰，注释完善，便于讲解

## 当前限制

作为学习和展示项目，存在以下限制：

1. **无后端服务**
   - 数据存储在本地 SQLite，没有云端同步
   - 没有真实的用户认证、订单管理接口

2. **商品数据模拟**
   - 商品库是预设的模拟数据，不是实时抓取

3. **AI 功能简化**
   - 基于规则的商品匹配，不是完整的推荐算法系统
   - 没有用户行为分析、协同过滤等高级功能

4. **多端数据不同步**
   - Android 和 PWA 是独立的，数据不互通

## 后续改进方向

如果继续开发，可以：

1. **搭建后端服务**
   - 使用 Spring Boot 或 Node.js 搭建 RESTful API
   - 实现用户管理、商品管理、订单管理接口
   - 数据存储迁移到 MySQL / PostgreSQL

2. **完善 AI 功能**
   - 记录用户行为（浏览、点击、加购、购买）
   - 引入协同过滤算法，基于用户相似度推荐
   - 建立用户画像，实现个性化推荐
   - 增加图像识别、语音输入等交互方式

3. **增强推荐系统**
   - 使用机器学习模型（如 CTR 预估）
   - A/B 测试验证推荐效果
   - 引入实时推荐引擎

4. **开发 iOS 版本**
   - 使用 SwiftUI 开发 iOS 原生 App
   - 或使用 Kotlin Multiplatform 实现跨平台共享层

5. **增加测试**
   - 单元测试（JUnit + Mockito）
   - 集成测试
   - UI 自动化测试（Espresso）

## 面试讲解建议

### 30 秒介绍
"这是一个 Android 购物助手项目。用户可以通过传统方式浏览商品，也可以用自然语言告诉 AI 需求，AI 会推荐合适的商品。技术上，我用 Java 实现了完整的商城流程，用 SQLite 存储数据，用 OkHttp 对接大模型 API。为了方便展示，还做了 PWA 版本，支持 iPhone 和浏览器访问。"

### 重点展示内容
1. **AI 助手流程演示**：输入需求 → AI 推荐 → 加购 → 下单
2. **技术架构讲解**：代码分层、数据流、API 对接
3. **工程化实践**：配置管理、.gitignore、兜底策略
4. **反思和展望**：当前不足、后续改进方向

### 诚实应对质疑
- 不是完整的推荐算法系统，是基于规则的商品匹配
- 没有后端服务，数据存储在本地
- 适合作为学习和展示项目，不是商业产品
