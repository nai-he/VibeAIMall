# Vibe Coding 改造记录

## 目标

把一个 Android 商城项目改造成更贴合 AI 工程师岗位的求职作品，重点体现独立交付、AI 原生交互和产研闭环。

## 改造步骤

1. 识别岗位关键词：AI 原生工具、Vibe Coding、Android 端功能落地、产品闭环。
2. 梳理现有项目：商城首页、购物车、订单、评论、个人中心、小游戏。
3. 确定减分项：发现页偏静态，订单状态入口不可点击，小游戏运行不稳定，AI 逻辑集中在 Activity。
4. 重构 AI 模块：新增意图解析、商品库、推荐引擎和推荐结果对象。
5. 恢复真实大模型 API：新增 `AiRemoteAdvisor`，通过本机配置注入 Key，失败时自动端侧兜底。
6. 统一工程底座：新增 `ProductRepository`、`CartService`、`OrderService`，减少重复逻辑。
7. 补业务闭环：推荐日志页、订单状态筛选、订单动作按钮、订单评价页。
8. 补产品页面：发现页改为 AI 产品实验室，个人中心入口全部绑定。
9. 补求职材料：README、演示脚本、面试问答和单元测试。

## 面试表达

这个过程体现的是用 AI 辅助开发快速拆解需求、定位问题、生成改造方案，并把功能落实到可运行代码和可演示链路里。
