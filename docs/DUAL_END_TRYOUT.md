# 双端试用说明

## Android

Android 可以直接安装原生 APK：

```text
E:\VibeAIMallDual\android\shixun\app\build\outputs\apk\debug\app-debug.apk
```

## iPhone / Android 浏览器

桌面双击：

```text
Vibe智购AI 总入口
```

选择第 3 项“启动 Android / iPhone 双端 PWA 试用”。它会启动本地网页服务。窗口里会显示两个地址：

- `http://localhost:5178`
- `http://你的电脑IPv4:5178`

手机和电脑连同一个 Wi-Fi 后，在手机浏览器打开第二个地址。

## 添加到桌面

iPhone：

1. 用 Safari 打开局域网地址。
2. 点底部分享按钮。
3. 选择“添加到主屏幕”。

Android：

1. 用 Chrome 打开局域网地址。
2. 点菜单。
3. 选择“安装应用”或“添加到主屏幕”。

## 体验链路

- 登录/注册：首次进入先注册或登录，刷新后保持登录，也可使用演示账号。
- 首页：搜索需求、高频场景、今日精选。
- AI：对话式购物，生成主推和备选方案。
- 商品：分类、搜索、详情、直接加购。
- 购物车：数量增减、删除、填写收货信息、提交订单。
- 订单：待付款、待收货、待评价、已完成、退款/售后状态流转。
- 我的：账号信息、AI记录、评价中心、Android/PWA/KMP 项目结构。
- 输入“预算3000学习平板”：AI 推荐商品。
- 输入“就买这个”：主推加入购物车。
- 输入“买备选1”：备选商品加入购物车。
- 输入“买一个出差续航充电宝”：推荐并自动加购。
- 输入“去购物车”：跳到购物车。
- 点击“提交订单”：生成待付款订单。
- 订单页依次点击“去付款”“确认收货”“去评价”：完成状态流转。
- 我的页点击“退出登录”：回到登录入口。

## 面试讲法

Android 端保留原生 App，iPhone 端提供 PWA 体验版，用同样的 AI 购物逻辑验证跨端产品闭环。后续如果进入真实双端工程，会把 AI 意图解析、推荐引擎、对话购买解析迁移到 Kotlin Multiplatform shared 模块，Android 继续原生 UI，iOS 使用 SwiftUI 接入 shared。
