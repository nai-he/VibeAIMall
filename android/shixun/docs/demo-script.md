# 面试演示脚本

## 1. 项目介绍

这个项目叫 Vibe智购AI，是我基于 Android 商城改造的 AI 购物助手。核心目标不是单纯展示商城页面，而是把用户的一句话需求转成可执行的购物决策，并打通真实大模型回复、商品推荐、加购、下单和订单状态流转。

## 2. 演示路径

1. 打开 App，进入首页。
2. 点击首页搜索框，输入“预算3000学习平板”。
3. AI 助手展示需求识别：学习场景、平板品类、3000 元预算。
4. 页面先输出主推商品、备选方案、推荐理由和购买建议；如果配置了 API Key，会继续展示真实大模型生成的导购回复。
5. 继续在对话框输入“就买这个”，AI 直接把主推加入购物车。
6. 再输入“买备选1”，演示备选方案也可通过对话购买。
7. 输入“去购物车”，切到购物车结算。
8. 下单后进入我的订单，展示待收货状态。
9. 回到个人中心，点击待付款、待收货、待评价、退款/售后，展示订单筛选。
10. 在订单卡片点击动作按钮，演示待付款到待收货、待收货到待评价。
11. 点击待评价订单的“去评价”，提交评价后订单流转为已完成，商品评论表同步写入。
12. 点击个人中心“AI记录”，展示 recommended、chat_added_to_cart、chat_recommend_and_add 等闭环日志。
13. 点击发现页，展示 AI 产品实验室和高频需求场景。
14. 点击小游戏，验证工具入口可用并可正常返回。

## 3. 讲解重点

- 我把 AI 推荐逻辑从 Activity 拆成独立模块，便于维护和测试。
- 我把对话购买指令拆成 `AiShoppingChatEngine`，支持“就买这个”“买备选1”“去购物车”。
- 商品数据由 `ProductRepository` 统一管理，首页、分类、详情和 AI 推荐共用同一份商品信息。
- 加购由 `CartService` 统一处理，订单状态由 `OrderService` 统一处理。
- 当前版本是“真实 API + 端侧兜底”的双引擎：配置 Key 时走大模型导购回复，没网或没 Key 时仍能稳定演示购物闭环。
- 推荐结果会写入本地推荐日志，形成需求识别到加购动作的闭环。
- 订单状态和个人中心入口都做了可点击流转，避免求职作品只有静态页面。
